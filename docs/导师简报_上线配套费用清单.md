# UP-SELF 上线配套费用清单｜导师简报版

核价日期：2026-10-22。对象：马来西亚 10～30 名学生，学习、作业、每周心情网站。

**我的选择：最低价试跑选 A；真正邀请学生试用，我更建议选 B，准备 RM120/月。** 以下是已核实公开套餐的搭配，不是“全网最低”承诺，也没有把官网价叫成真实结账价。未登录购买控制台，地区库存、域名可用性、付款币种和最终账单仍需开通当天确认。

## 先用一句话向导师解释

> 我们租一台一直开着的网上电脑，把网站和数据库放在里面。Windows、Mac 和手机都访问同一个网址，所以账号、课程、作业和心情都是同一份数据。先买月付，备份另外保存，试用后再决定是否扩容。

## 所有配套都已经选好的公共部分

- **域名：Porkbun 的普通 `.com`**，官网首年和一年续费当前均为 **US$11.08/年**；准备 **RM55/年**作为域名、可能税费和支付差额预算。具体名字由项目确认，未查可用性，不选溢价域名。[域名价格](https://porkbun.com/products/domains)
- **DNS：使用域名商自带的基础解析；HTTPS：Let's Encrypt 免费证书。** 这两项无需额外订阅。[免费 HTTPS](https://letsencrypt.org/about/)
- **支付：使用本人已有、支持海外付款的 Visa/Mastercard 信用卡或借记卡。** 若账号显示 MYR 结账就按实际 MYR 总额核对；若美元结账则看发卡行换算。下文统一按 **US$1＝RM4.10，月服务费预留 8%税及 3%支付汇差**估算，3%不是银行统一收费，不要重复叠加已含费用的实际汇率。[阿里云税说明](https://www.alibabacloud.com/en/notice/important_notice_malaysian_service_tax_rate_increase_2df?_p_lc=1%3F_p_lc%3D1)、[DO 税说明](https://docs.digitalocean.com/platform/billing/taxes/mys/)、[AWS 税说明](https://aws.amazon.com/tax-help/malaysia/)、[银行卡要求](https://www.alibabacloud.com/help/en/user-center/support/payment-faq)
- **一次性部署人工：按自己完成计算，额外外包付款 RM0，但需要实际花时间做安装、迁移和测试。** 如果请别人部署，先取得另行报价，不把无限人工包含在下面的月费里。
- **同一台服务器运行前端、Java、MySQL和Redis。** 视频/图片/作业文件先保留现有受控文件存储，不另买应用数据库、视频平台、短信或邮箱服务；Node/Maven用现有电脑构建，不另外租构建服务器。
- **软件版本候选：** Linux x86_64，拟选 Ubuntu 22.04 LTS；JDK 按参考 Docker 的 **Amazon Corretto 8u362（Java 8）**，MySQL **5.7.44**，Redis Linux **5.0.14**，Spring Boot **2.5.14**、Flyway **7.7.3**等业务依赖保持原样。Corretto 免许可费，不要求把主机买在 AWS。[Corretto 说明](https://aws.amazon.com/corretto/faqs/)

版本说明：这只是部署候选清单，尚未做 Linux 适配验收；当前本机是 Oracle JDK 8u231、Redis Windows 5.0.14.1，不能将 Linux 候选称为完全相同的二进制，也不会在本轮修改它们。旧版组件的兼容性、维护和许可事项在付款前确认，详见[完整费用与上线流程](正式上线全流程与费用预算.md)。

## A. 最低价试跑配套：阿里云 2GB

- **主机：** 阿里云国际站 Simple Application Server，选择新加坡、Linux x86_64、**1核 / 2GB内存 / 40GB磁盘 / 1.5TB月流量 / 6Mbps峰值带宽**，公开价 **US$9/月**，先月付。[购买及价格](https://www.alibabacloud.com/en/product/swas/pricing)、[地区说明](https://www.alibabacloud.com/help/en/simple-application-server/product-overview/regions-and-network-connectivity)
- **域名与入口：** 上述 Porkbun `.com`＋基础 DNS＋Let's Encrypt，域名年费预留 RM55，DNS/证书费 RM0。
- **备份：** 每天导出数据库和匹配文件，加密后保存到 **Cloudflare R2 Standard 私有桶**，保留最近 7 天；预算按**所有保留副本合计平均 20GB**计算。10GB-month 免费后，存储约 **US$0.15/月**，假设请求在免费额度内。它只用于备份，不改现有网站文件存储。[R2 价格](https://developers.cloudflare.com/r2/pricing/)
- **价格：** 主机＋备份 **US$9.15/月，税前**；按公共假设估算，月付服务约 **RM41.73**，连域名年费摊销后平均 **RM46.32/月**。
- **付款准备：** 首月服务＋一整年域名的估算基线 **RM96.73**；建议**首次准备 RM120，之后每月预算 RM60**。不另购买厂商付费整机备份，恢复依靠数据库、文件副本和代码重新建立。
- **适用范围：** 老师演示、很少人同时操作的试跑。内存较紧，6Mbps不适合多人集中看视频；**不把这个价格当成已保证 30 人同时可用的正式配置**。

## B. 我建议向导师申请的省钱配套：阿里云 4GB

- **主机：** 同为阿里云国际站、新加坡、Linux x86_64，改选 **2核 / 4GB内存 / 80GB磁盘 / 4TB月流量 / 15Mbps峰值带宽**，公开价 **US$19/月**，先月付。[购买及价格](https://www.alibabacloud.com/en/product/swas/pricing)
- **域名与入口：** Porkbun `.com`，年费预留 RM55；基础 DNS＋Let's Encrypt 免费。
- **备份：** 使用 A 的每日数据库＋文件加密备份到 R2、保留最近 7 天方案，总保留量按平均 20GB估算，约 **US$0.15/月**。[备份存储价格](https://developers.cloudflare.com/r2/pricing/)
- **价格：** 主机＋备份 **US$19.15/月，税前**；预估月付服务约 **RM87.34**，含域名摊销平均 **RM91.92/月**。
- **付款准备：** 首月服务＋全年域名的估算基线 **RM142.34**；建议**首次准备 RM180，之后每月预算 RM120**。六个月基线约 **RM579.04**，申请六个月预算可按 **RM800**准备余量。
- **适用范围：** 10～30 名受邀学生分散使用、错峰观看。4GB给 Java和数据库更多空间，但15Mbps仍需试播；若要全班同时看视频，应选 C 或根据实测另调资源，不靠增加内存解决带宽问题。

## C. 备份操作较省心：DigitalOcean 4GB

- **主机：** DigitalOcean Basic Regular，选择 Singapore，**2 vCPU / 4GiB / 80GiB / 4,000GiB月流量**，公开价 **US$24/月**。[购买及价格](https://www.digitalocean.com/pricing/droplets)
- **域名与入口：** 同样使用 Porkbun `.com`，预留 RM55/年；基础 DNS和Let's Encrypt 免费。
- **备份：** 开启厂商**每日整机备份，US$7.20/月**，按主机费30%计；另在机内每天生成一致性数据库及文件备份，方便恢复。**不再加购 R2，避免重复付费**；定期将加密副本另存本人电脑。厂商保留规则以下单页为准。[备份价格](https://www.digitalocean.com/pricing/droplets)
- **价格：** 主机＋每日备份 **US$31.20/月，税前**；预估月付服务 **RM142.30**，含域名摊销平均 **RM146.88/月**。
- **付款准备：** 首月服务＋全年域名的估算基线 **RM197.30**；建议**首次准备 RM240，之后每月预算 RM180**。
- **适用范围：** 愿意多付一点，换较直观的整机恢复方式。仍要测试视频、权限和备份恢复，不能因为买了4GB就承诺无限并发。

## D. AWS 备选配套：Lightsail 4GB

- **主机：** AWS Lightsail，选择 Singapore、Linux/Unix、**含公网IPv4**，**2核 / 4GB / 80GB / 4TB月流量**，公开价 **US$24/月**。[购买及价格](https://aws.amazon.com/lightsail/pricing/)
- **域名与入口：** Porkbun `.com`，预留 RM55/年；免费基础DNS和Let's Encrypt。静态IP绑定在实例上，不把它闲置保留。[静态IP计费](https://docs.aws.amazon.com/lightsail/latest/userguide/amazon-lightsail-frequently-asked-questions-faq-billing-and-account-management.html)
- **备份：** 每天数据库/文件备份并开每日快照；快照按 **US$0.05/GB/月**计费，先预留 **US$4/月**，相当于约80GB计费快照数据的假设。**US$4是预算，不是固定包价或封顶**。不额外加 R2；定期下载加密副本另存。[快照价格](https://aws.amazon.com/lightsail/pricing/)
- **价格：** 主机＋快照预算 **US$28/月，税前**；预估月付服务 **RM127.70**，含域名摊销平均 **RM132.29/月**。
- **付款准备：** 首月服务＋全年域名估算基线 **RM182.70**；建议**首次准备 RM225，之后每月预算 RM165**。快照持续增长时重新核算。
- **适用范围：** 希望使用 AWS 控制台的备选。注意新加坡流量超额的单价，不能把“含4TB”理解为无限流量。[流量规则](https://docs.aws.amazon.com/lightsail/latest/userguide/amazon-lightsail-faq-data-transfer-allowance.html)

## 付款前最后核对，避免把预算当报价

- **真实结账价现在还没有取得。** 目前只核到公开价；实际付款前记录“厂商/账号、Singapore、准确规格、订单税前价、SST、付款币种、备份、全年域名及银行费用”，不能用上述估算冒充已下单账单。
- 阿里云、DO、AWS的马来西亚适用主机税率已核为8%；为了统一比较，上面暂对整笔月服务费都留8%税，**R2等其他服务的实际税项仍按自己的发票核对**。3%只是汇差/支付余量，域名RM55也是预留，余量未用不等于必须花掉。
- A/B 的R2费用假设该账号没有被其他项目耗尽免费额度，保留副本平均合计20GB且请求在免费额度内。视频增多、多版本累积会增加存储；每日备份任务和恢复脚本仍需部署并实测，不是现在已经自动运行。备份存放地区先满足学校要求；若要求马来西亚本地存放，则换合适的备份服务并重算。
- 所有套餐都不含外包维护、未知软件授权、额外磁盘、超额流量和新增业务服务；开通前完成旧组件兼容性/许可及真实数据上线核对。主机月流量已经包含，不需要正常使用时再买一份流量包。
- 域名名字和最终可用性尚未确认；普通`.com`价格不适用于溢价名。新用户优惠、学校免费服务器及赠送额度没有计入长期预算。

计算口径：`月服务美元 × 1.08 × 4.10 × 1.03`；首月基线再加域名全年预留RM55，月平均则加`RM55÷12`。使用未四舍五入的中间值汇总，金额仅用于预算。之前完整报告中的DO方案仍然有效，本清单新增A/B，是在“优先省钱”的条件下选择自行维护备份的另一种搭配，并没有实际切换部署方案。
