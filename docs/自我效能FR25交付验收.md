# FR-25：自我效能评估

日期：2026-10-23。沿用独立UP-SELF工程的六模块Java、Spring Security/JWT/Redis、MyBatis XML、PageHelper、BaseController及Vue结构。没有新增依赖、中间件或修改参考项目。

## 实际业务范围

- 学生 **My check-in** 内切换 **My mood / Self-belief**，主菜单保持5项。原心情网址和每周一次规则不变。
- Self-belief采用GSE-3英文三题和五级原选项，不预选答案，一次呈现一题，可前后返回。三题完整回答后由后端计算均值，保存到小数点后两位。
- 首次可填写，随后从上次记录的马来西亚日期起间隔28天；第28天当地零点起可再填写。该频率是本项目产品规则，不是量表规定的必需频率。不能补填过去日期、修改或删除已提交记录；保存前可返回修改或取消。
- 学生查看自己的历次答案、分数、历史分页及4/12/26/52周趋势。图表横坐标使用真实日期，仅呈现已保存点；线段连接实际记录，不产生缺失日期的分数。没有成绩排名、风险阈值、诊断或与心情合并的总分。
- **独立首次共享告知**：原心情确认不能代替自我效能确认。当前负责学生已加入且已发布课程的有效导师，只读查看已确认共享的日期、分数和趋势；逐题答案仅学生自己查看。
- 学生 **My check-in** 与导师 **Students → Student check-ins** 使用同一组已有课程关系。撤销选课、课程归档或更换导师后，原导师的后续读取立即被拒绝。管理员与内部maintenance不能借通配权限读取自我效能记录。
- 没有新增自我效能私人备注；已有心情私人备注仍仅学生可见。

## 问卷来源、计分与边界

使用Doll、Nießen、Schmidt、Rammstedt及Lechner（2021）的[General Self-Efficacy Short Scale-3 English adaptation](https://doi.org/10.6102/zis294)，[官方完整说明](https://access.gesis.org/zis/1435)第2节给出原题、五级响应和完整三题无权均值规则。版本标识`GSE-3-EN-2021-v1`与每条记录一起保存；题目及选项由后端提供，前端不另造一套问卷或计分。

量表内容许可为[CC BY-NC-SA 4.0](https://creativecommons.org/licenses/by-nc-sa/4.0/)。UI的About this check-in、[后端量表常量](../up-self-biz/src/main/java/com/upself/biz/selfefficacy/service/SelfEfficacyScale.java)均保留署名、来源和许可。保留原英文措辞与计分，只将展示改为逐题、无倒计时；相关量表内容/展示说明按同一许可提供。这项许可声明针对量表内容，不宣称替项目所有其他代码重新授权。

原验证样本为英国/德国母语成年人，不能直接宣称已针对马来西亚神经多样性学生验证。当前属于毕业项目的自我反思功能，功能验收不等于完成本地心理测量学验证。未来如做研究、改写或翻译题目，需要单独处理相应研究与量表验证问题；本轮没有改写题目或创造常模分段。

计分示例：三个答案1、2、2，均值为1.67。缺题、越界或非整数选项不计分；客户端提交的score或studentId不作为依据。心情趋势与自我效能趋势在不同页面，避免将两种含义和频率不同的数据当成同一指标。

| Mapper/XML | [SelfEfficacyMapper.xml](../up-self-biz/src/main/resources/mapper/selfefficacy/SelfEfficacyMapper.xml)，查询重复限制当前导师/学生/课程状态；导师SQL仅选日期、分数及量表版本 |
| 前端 | `frontend/src/features/self-efficacy`内分API/类型/文案、学生/导师页面、逐题表单、历史和趋势组件；不把业务数据放入全局store |
| 入口组合 | AppLayout负责心情/自我效能导航分组；两项的表、API、共享告知和计分独立，不互相读取私人数据 |

保存事务以学生行`FOR UPDATE`锁串行化同一学生的确认/保存，在同一事务中检查最近记录，再写入原始三项和均值。数据库另有`(student_id,assessment_date)`唯一约束。并发/重复请求仅保存一次，后续请求409；不会覆盖原答案。

历史接口采用原`startPage()/getDataTable()`。分页前的权限查询不放在startPage之后，以免抢占PageHelper上下文；最终历史SQL仍重新限制共享告知及课程关系，避免仅靠前置校验。

## API与权限

学生权限`efficacy:own:read`及`efficacy:own:record`；导师只分配`efficacy:students:read`。沿用现有学生/管理两条认证链，不新增角色。

| 方法 | 学生路径 | 返回 |
|---|---|---|
| GET | `/client/self-efficacy/current` | 当前日期、量表、告知状态、可见导师、最近记录、下次可填写日期 |
| POST | `/client/self-efficacy/acknowledgment` | body：noticeVersion、accepted=true；不能用旧版本或心情告知替代 |
| POST | `/client/self-efficacy/entries` | body：assessmentDate、instrumentVersion、answers（三个1～5整数）；服务端取身份并计分 |
| GET | `/client/self-efficacy/history?current=1&pageSize=10` | TableDataInfo，本人记录及原始答案 |
| GET | `/client/self-efficacy/trend?weeks=26` | AjaxResult.data，范围和真实日期的分数点 |

导师使用GET `/self-efficacy/students/{studentId}`、`/history`及`/trend?weeks=26`。历史返回TableDataInfo，趋势返回AjaxResult；共享记录只有assessmentDate/score/instrumentVersion。没有导师写入接口。

错误码沿用项目约定：400参数、401未登录/失效、403角色/告知/课程关系、409过期页面或当前周期已保存。前端同时读取HTTP及JSON业务码，失败保留输入，可重试；离开未保存表单会确认。

## 英文及inclusive设计

一题一屏、固定五级文字选项、原生radio键盘操作、无默认答案/倒计时/自动跳题；选择后仍由学生按Next。返回保留选择，新题将焦点移到题目。只在入口/标题使用辅助emoji，不把情绪表情当自我效能选项。

继续沿用字号、高对比、减少动态效果和Aa入口；提供短英文成功/失败状态、空记录、图表/表格切换及分页。来源和长说明可展开阅读，默认不要求阅读大段技术文字。
