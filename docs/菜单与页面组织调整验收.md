# 菜单与页面组织调整

日期：2026-10-23。范围：仅调整已有页面入口、导航和布局。没有新增业务功能、权限、接口、依赖或数据库迁移；FR-25仍未开发，当前数据库仍为V8。

## 现在怎么找功能

| 角色 | 主入口 | 页面内分组 |
|---|---|---|
| Student | Home / My learning / Assignments / My mood / My goals | My learning → My courses / Saved courses / Learning history |
| Mentor | Home / Teaching courses / Assignments / Students | Students → Student overview / Student mood |
| Administrator | Home / Accounts / Course allocation | 原账号管理和课程分配功能 |
| Internal maintenance | 保留内部Home / Accounts / Course allocation | 仍由`/#/internal/login`进入，不加入普通登录角色选项 |

学生右上角 **Aa** 打开原Reading settings页面。保留字号、对比度、减少动态效果及恢复默认设置，存储规则不变。学生首页标题改为 **Welcome back**，避免与My learning主入口同名；首页已有继续学习等功能保留。

课程列表和收藏页移除了重复的收藏/课程快捷链接，由页面上方固定位置的分组导航承接。课程详情内的收藏、章节阅读、学习进度等操作均保留。

## 保持的行为

- 原网址全部保留，包括`/#/student/courses`、`/#/student/saved-courses`、`/#/student/history`、`/#/mentor/students`、`/#/mentor/mood`和`/#/preferences`；刷新、前进后退及直接打开旧链接仍可用。
- 原Vue路由定义与守卫未修改。API、认证会话、角色权限、数据范围和后端源码未修改。菜单分组不授予新权限。
- 收藏入口继续检查`learning:bookmark:own`，目标入口继续检查`goals:own`，账号入口继续检查`system:user:list`；正常学生授权账号显示5个主入口。
- 本轮没有新迁移，不需要为了菜单调整退出登录或导入数据库；现有V8升级新增权限仍遵循原来的重新登录规则。

## inclusive及代码组织

- 主导航与页面内导航分别命名，使用真实链接，不做层层下拉或隐藏侧栏。
- 当前分组用下划线、文字加粗及背景共同表示，提供`aria-current`；进入课程详情仍标亮My learning，查看导师学生心情仍标亮Students。
- 图标仅辅助辨认，始终保留英文文字；Aa有Reading settings的无障碍名称和鼠标提示。
- 导航点击区域至少44px高。小屏自动换行，避免横向滑动才能发现入口；沿用原高对比、字号和减少动态效果设置。
- 仅新增一个展示组件[NavigationLinks.vue](../frontend/src/shared/ui/NavigationLinks.vue)，不读取角色或请求API。角色分组及当前项计算集中在[AppLayout.vue](../frontend/src/app/layouts/AppLayout.vue)，功能页面保留独立逻辑，不增加全局导航store。
- 新文案置于[英文消息文件](../frontend/src/shared/i18n/en.ts)，多语言切换仍未开放。
