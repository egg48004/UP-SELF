## 3. 日常启动与关闭

在安装目录双击：

- `start.cmd`：启动 MySQL 和 Redis；已启动时不会重复启动。
- `status.cmd`：查看二进制版本和本地端口状态。
- `stop.cmd`：优雅关闭两个实例；Redis 保存数据。
- `dev-shell.cmd`：打开配置了 JDK、Maven、MySQL 和 Redis 命令路径的开发终端，仅影响该终端。

也可以在 PowerShell 执行：

```powershell
& 'C:\Users\eggma\Documents\Codex\local-env\up-self\scripts\start.ps1'
& 'C:\Users\eggma\Documents\Codex\local-env\up-self\scripts\status.ps1'
& 'C:\Users\eggma\Documents\Codex\local-env\up-self\scripts\stop.ps1'
```

当前安装采用普通用户后台进程，**未注册 Windows 服务、未设置开机自启**。电脑重启后运行 `start.cmd`。目前两个服务已启动，只监听本机回环地址；学生不能通过该本地环境远程使用系统。正式上线另行部署。

在 `dev-shell.cmd` 打开的终端中连接空数据库：

```powershell
mysql --defaults-extra-file=secrets/mysql-app-client.cnf up_self_dev
```

不需要把密码放在命令行上。迁移和管理分别使用 `mysql-migration-client.cnf`、`mysql-root-client.cnf`。

## 4. 配置文件与后续工程

- MySQL：安装目录 `config/my.ini`。
- Redis：安装目录 `config/redis.conf`。
- 后续独立毕业工程的连接配置草稿：`config/application-local-connections.yml`。
- MySQL 数据：`mysql/data`；Redis 数据：`redis/data`。

连接配置草稿保持参考项目的数据源、Redis 和 Flyway 配置组织方式。它没有写入参考项目，也没有创建毕业项目。待开发标准确认、独立工程建立后，再核对最终启动 profile 并接入；不要将其直接覆盖参考配置。Flyway 使用参考项目 `7.7.3` 依赖和 `classpath:db/draft` 组织方式，但此次没有运行任何迁移。后续必须为毕业项目编写独立迁移，不能执行参考业务脚本。

JDK 路径为 `C:\Program Files\Java\jdk1.8.0_231`；Maven 路径为 `C:\Program Files\Apache\apache-maven-3.10.0`。未修改全局 PATH 或升级现有 Java/Maven。沙箱环境中 Maven 默认仓库可能错误落到 `C:\.m2`；之前用显式可写仓库验证过七个 POM，此问题不构成重新安装 Maven 的理由。
