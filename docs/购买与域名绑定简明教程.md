# UP-SELF 购买与域名绑定简明教程

更新日期：2026-10-22。适合马来西亚 10～30 名受邀学生试用。

**顺序：本地准备 → 买服务器 → 部署并测试 → 买域名 → DNS 指向 → 配置 HTTPS → 备份与验收 → 开放使用。**

本文是操作路线，没有实际购买、创建服务器或部署。所有 IP、域名均为示例；实际付款前核对结账价和库存。服务器不是买来就自动有 UP-SELF，仍需安装和部署。

## 1. 购买前先准备好项目

- **在哪里：** 自己电脑的 VS Code，现有 UP-SELF 项目。
- **做什么：** 验证现有功能，准备 Linux 启动、Nginx、正式配置和备份方案，确定上线使用空库还是迁移本地数据。
- **注意：** 当前 Windows 启动成功不代表 Linux 已通过验收。保持已确认的依赖版本；Ubuntu 22.04 LTS x86_64 是待验证候选系统，先完成兼容性验证再付款。不要直接安装“最新版”替换参考版本。
- **完成标志：** 有可部署的前端打包文件、后端 JAR、配置模板和数据迁移方案。

## 2. 买一台云服务器

- **在哪里：** [阿里云国际站轻量应用服务器](https://www.alibabacloud.com/en/product/swas)，登录本人账号，进入购买页面。
- **选什么：** Simple Application Server（轻量应用服务器）；Singapore（新加坡）；Linux 系统镜像、x86_64，优先检查 Ubuntu 22.04 LTS 是否提供并通过上一步验证；不要选 Windows 或预装 WordPress 的应用镜像。
- **套餐目标：** 2核、4GB内存、80GB磁盘、4TB月流量、15Mbps峰值带宽。公开价格表当前为 US$19/月，属于预算依据，未取得真实订单报价。实际地区套餐不同则先核对，不自动换购。
- **付多久：** 先选 1 个月；官方支持按月、按年预付，不是六个月起付。检查自动续费选项，设置到期提醒。
- **付款前看：** 地区、系统、规格、公网 IPv4、月流量、超额流量规则、税、付款币种和续费价。保存订单总额；不把促销首月价当长期月费。
- **买完记录：** 实例名称、公网 IPv4、到期日。SSH 密钥单独安全保存，不放进 GitHub。
- **完成标志：** 控制台里有一台运行中的服务器，并知道公网 IP。

[官方套餐与价格](https://www.alibabacloud.com/en/product/swas/pricing)。详细预算见 [导师简报费用清单](导师简报_上线配套费用清单.md) 的 B 配套；建议预留 RM120/月、首次 RM180，这些是预算余量，不是结账报价。

## 3. 把项目部署到服务器，先通过 IP 测试

- **在哪里：** 阿里云控制台查看实例和防火墙；自己电脑通过 SSH 终端连接服务器，执行安装和配置。
- **放什么：** 同一台服务器运行 Nginx、Java 后端、MySQL、Redis，保存上传文件；Vue 前端本地构建后上传 dist。初期不用另租构建服务器。
- **网络：** 网站开放 80/443；SSH 22 尽量只允许本人当前公网 IP。MySQL 3306、Redis 6379、后端 8080 不向公网开放。
- **数据：** 空库由 Flyway 初始化；如果保留本地数据，数据库与对应上传文件成套恢复。以后更新只执行新增迁移，不覆盖已有数据。
- **正式配置：** 使用独立的数据库应用账号和正式密码、密钥；本地 root 密码无需因此改变。正式凭证不能继续公开提交。正式使用前应更换曾公开上传且被线上使用的凭证。
- **完成标志：** 临时通过公网 IP 能打开页面、登录；浏览器实际测试三种角色。此时未配置 HTTPS，只用测试数据验证，不收集学生真实数据。

## 4. 买一个域名

- **在哪里：** [Porkbun 域名查询与购买](https://porkbun.com/products/domains)。
- **选什么：** 查询喜欢的名字，优先普通、非溢价的 .com，先买 1 年。示例 upself-example.com 不代表可注册或已购买。
- **付款前看：** 首年价格、下一年续费、税费和最终金额；避免误买 Premium 溢价域名或勾选附加服务。完成注册商要求的邮箱验证。
- **DNS 放哪里：** 继续用 Porkbun 默认的域名服务器和 DNS 管理，不需要转到阿里云，也不需要再注册 Cloudflare 来绑定域名。
- **完成标志：** Porkbun 的 Domain Management 中能看到自己的域名。

服务器和域名可以在不同公司购买。服务器负责存放网站；域名负责让人记住网址。

## 5. 设置 DNS：把域名指向服务器

- **在哪里：** Porkbun → ACCOUNT → Domain Management → 找到域名 → Details → DNS Records 编辑入口。界面名称以后可能调整，以当时控制台为准。
- **先准备：** 从阿里云实例详情复制公网 IPv4。下面 203.0.113.10 是文档专用示例，必须换成自己的真实 IP。
- **添加两条记录：** 为了操作简单，两条均使用 A 记录。

| Type | Host | Answer | TTL |
|---|---|---|---|
| A | 留空，代表根域名 | 服务器真实公网 IPv4 | 默认 |
| A | www | 同一个服务器真实公网 IPv4 | 默认 |

Porkbun 根域名的 Host 留空；之前通用说明里的 @ 也是根域名含义，但不要机械地在本平台输入 @。Answer 只填 IP，不填 https://、端口或目录。

- 删除或替换同名、冲突的停车页 A/ALIAS/CNAME 记录；不删除无关邮件 MX/TXT 等记录。如有指向其他服务器的 AAAA 记录，确认未使用 IPv6 后移除，避免部分设备访问错误地址。
- 保存后等待 DNS 缓存更新；不保证立即生效，也不要因暂时未更新而反复改记录。
- **检查方式：** 在 Windows PowerShell 或 Mac 终端执行 `nslookup 你的域名` 与 `nslookup www.你的域名`，确认解析到目标 IP。
- **完成标志：** 两个名字都能解析到正确服务器。DNS 正确只是“找到服务器”，还需要下一步让服务器展示正确网站。

[官方 A 记录操作图解](https://kb.porkbun.com/article/54-how-to-use-a-records-to-point-your-domain-at-a-web-host)。

## 6. 服务器接收域名，配置 HTTPS

- **在哪里：** 通过 SSH 在服务器配置 Nginx；不是在域名商上传项目。
- **做什么：** Nginx 配置根域名和 www，对外展示 Vue 前端，将 /api 转发到本机 Java 后端；页面刷新、上传和媒体访问均要验证。
- **证书：** 使用 Let's Encrypt，通过服务器上的 ACME 客户端（例如 Certbot）申请证书，覆盖根域名和 www，并配置自动续期及续期测试。不用在 Let's Encrypt 网站下单。
- **统一入口：** 选根域名为正式地址，www 跳转到根域名；HTTP 跳转 HTTPS。先确保域名解析和证书验证正常，再完成跳转配置。
- **权限：** 视频、图片和作业附件继续遵守应用权限，不把整个上传目录直接公开。
- **完成标志：** 浏览器用 https://你的域名 正常访问，无证书警告；www 也能正确跳转。

[Let's Encrypt 入门说明](https://letsencrypt.org/getting-started/)。申请和续期方式需在实际部署时结合 Nginx 配置验证。

## 7. 配置备份，最后邀请学生

- **在哪里：** 服务器配置每日任务；本配套另在 [Cloudflare R2](https://developers.cloudflare.com/r2/pricing/) 配置私有备份存储。
- **选什么：** R2 Standard 私有桶，仅保存加密的数据库与匹配文件备份，保留最近 7 天；确认学校允许的备份存放地区。它不替换现有应用文件存储，也不是绑定域名的必要步骤。
- **费用：** 以实际总保留量、请求和免费额度核算，不假设永远免费。之前 US$0.15/月仅是总保留量平均20GB且其他条件满足时的估算。
- **验收：** 实际恢复一次备份；测试管理员建课分配、导师上传发帖和批改、学生观看提交及心情记录，检查私人备注不被导师读取。
- **完成标志：** HTTPS、三角色功能、备份恢复、后台运行和开机启动全部通过，再邀请少量学生试用。

## 哪些先不用买

| 项目 | 当前处理 |
|---|---|
| 第二台服务器、独立云数据库、云 Redis | 暂不购买，先同机运行 |
| Windows 系统、服务器桌面、远程桌面软件 | 不购买，使用 Linux + SSH |
| 域名商的网站空间、建站套餐、WordPress 托管 | 不购买，已有自己的 Vue + Java 网站 |
| 付费 SSL 证书、付费 DNS | 不购买，使用基础 DNS 和 Let's Encrypt |
| CDN、视频点播套餐、应用对象存储 | 暂不购买；先实测视频并发和带宽，必要时再评估 |
| 流量加购包、额外磁盘 | 暂不加购，先看套餐额度并设置用量提醒；超额仍可能收费 |
| 企业邮箱、短信、付费邮件服务 | 当前功能不依赖，暂不购买 |
| 负载均衡、Kubernetes、自动部署平台 | 当前规模不需要 |
| 阿里云付费整机备份 | 本配套先用异地数据库/文件备份，不重复购买；恢复能力必须实测 |

## 最后记住这四件事

1. **不是六个月起付。** 服务器先买月付；域名通常按年买，二者分开续费。
2. **云服务器全天运行。** 自己电脑关机不影响网站；关闭服务器不代表自动退款或停止计费，注意到期及资源释放规则。
3. **GitHub 不等于部署。** 后续发布新功能仍需备份、打包、更新程序、执行新增 Flyway 迁移和验证，不能重新导入旧库覆盖学生数据。
4. **绑定域名不用再买一台机器。** DNS 找到服务器，Nginx 展示网站，HTTPS 保护浏览器连接，三步配合完成。
