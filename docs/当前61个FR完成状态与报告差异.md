## 建议修订报告的业务约定

| 项目 | 报告/早期设想 | 当前应写入报告的实际行为 |
|---|---|---|
| FR-05、FR-57 | 自动进度、监控学习活动 | 自动保存访问章节；学生标记完成；导师查看完成数，不监控视频秒数 |
| FR-06 | 完成活动历史 | 当前可访问的已完成章节清单，撤销后移除；不是不可变审计 |
| FR-14 | 截止前重新提交 | 导师退回后重新提交，保留尝试历史；允许迟交并标记 |
| FR-17 | 编辑/删除作业 | 编辑/归档，保存历史提交 |
| FR-19～21 | 每日签到/每日心情 | 只做自愿每周心情，无每日签到和连续打卡奖励 |
| FR-53 | 管理员管理作业 | 导师负责作业及正文；管理员负责账号、课程及分配 |
| FR-61 | 一对一预约 | 仅课程会议公告，不能描述为完整预约系统 |
| 角色与界面 | 角色描述较粗 | 对外学生/导师/管理员；maintenance内部入口；后端控制数据范围 |
| 心情权限 | FR表未列详细规则 | 首次告知确认；当前有效课程导师只读；私人备注仅学生 |
| 课程范围 | 浏览可用课程 | 管理员分配成员；学生仅见已加入且已发布的课程 |

这些是已确认的实际范围，不要求为了凑FR而恢复每日打卡、管理员读取作业或增加风险算法。
