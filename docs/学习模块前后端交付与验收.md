## 2. 这次解决了什么

此前页面只有账号、权限文字及账号操作区，学习接口存在，但没有学习功能页面；不是所有权限文字都能点击。本次新增完整 Vue 页面与交互，未把说明文字包装成假按钮。

学生使用课程卡片和阅读布局。导师、管理员、维护共用管理布局和业务组件；权限决定可用操作，后端继续检查角色和课程归属。前端隐藏按钮不替代服务端鉴权。

| 身份/页面 | 当前真实操作 | 后端联动与结果 |
|---|---|---|
| 登录/账号 | 双入口登录、刷新恢复、本人改密、退出 | 继续使用账号密码、JWT + Redis、入口角色检查及会话失效机制 |
| 管理课程 | 新建/编辑、搜索/清空、翻页、分配导师 | MySQL 保存；无导师不能发布；候选账号按角色搜索与服务端分页 |
| 管理成员与发布 | 加入/移除学生、草稿、发布、归档、恢复发布 | 移除成员/课程下架后学生实际访问被拒绝，不只是页面隐藏 |
| 导师章节 | 新建/编辑/删除、排序号、草稿/发布、预览、返回 | 仅允许负责课程；未保存离开提示；章节查询与修改均走真实接口 |
| 导师资源 | 上传图片/视频/WebVTT、进度、取消、预览、修改元数据、删除 | 私有文件保存；服务端校验大小/类型；图片替代说明、字幕关联、文字稿及语言字段 |
| 导师帖子 | 文字公告、会议链接、草稿/发布、本人编辑/下架/删除 | MySQL 保存；会议网址只接受受支持的 HTTPS 链接；管理权限不自动等同于冒用导师身份发帖 |
| 学生课程 | 搜索/清空/翻页/进入课程、章节索引、前后章节、动态切换 | 只返回本人加入且已发布的内容；不提供公开选课/自助报名 |
| 学生媒体 | 图片、视频播放/暂停/拖动、字幕、展开文字稿、失败重试 | 获取短期媒体访问票据，支持视频 Range 请求；不把登录 JWT 放进媒体 URL |
| 阅读设置 | 三种字号、高对比、减少动态、重置 | 本机保存非敏感偏好，刷新后恢复；暂无跨设备同步 |
| 账号管理 | 搜索/清空/分页、新建/编辑、角色/状态、重置密码 | 沿用既有受限账号 API；受保护账号操作继续由后端拒绝；TOTP 关闭时不显示无用重置入口 |

## 4. 封装与依赖边界

```text
frontend/src/
  app/                    路由、布局、启动接线
  features/
    auth/                 登录 API、身份状态、登录/本人安全页
    accounts/             管理账号 API 与页面
    learning/
      api.ts              学习接口封装
      types.ts            课程/章节/资源/帖子契约
      pages/              学生列表/阅读、管理列表/工作区、章节编辑
      components/         课程表单、成员选择、上传、阅读器、媒体、帖子
    preferences/          阅读设置、本机偏好、系统朗读
  shared/
    http/                 请求、响应类型、媒体地址约束
    auth/                 会话存储、纯权限判断
    i18n/                 英文及语言注册
    styles/               样式变量和基础样式
    ui/                   错误/加载/空态、分页、确认对话框
```

页面负责组合流程；API 不导入页面；HTTP 不导入业务 store/router。401 回调由启动层接线，避免请求层与路由循环依赖。课程领域状态留在对应页面，Pinia 不承接所有表单。学生和管理端共享读取/媒体/帖子组件，不强行共用一张大页面。新增作业或心情时增加各自 feature/API/类型，复用已有请求、身份、布局和基础反馈，不提前建立万能 CRUD 或动态表单平台。

后端新增/对齐位置（均在独立项目）：

- `up-self-common/.../core/controller/BaseController.java`：`startPage/clearPage/getDataTable/toAjax`。
- `up-self-common/.../core/page/{PageDomain,TableSupport,TableDataInfo}.java` 与 `utils/PageUtils.java`。
- `up-self-admin/src/main/java/com/upself/web/controller/learning/LearningController.java` 与同级 `system/SysUserController.java`：继承基类；分页结束清理 PageHelper 状态。
- 账号 Service/ServiceImpl、Mapper/XML：增加角色候选查询；只返回选择所需字段，不额外授予导师全站账号权限。
- `SysLoginController.getInfo`：返回实际 `totpEnabled`，前端按现有关闭状态展示。

common 路径中的 `...` 表示模块内 `src/main/java/com/upself/common`，具体类可按文件名搜索。参考依据为只读工程的 `ac-fts-common/src/main/java/com/saas/common/core/controller/BaseController.java`、`core/page/TableSupport.java`、`core/page/TableDataInfo.java`，没有复制其无关交易业务辅助方法。

列表请求统一 `current/pageSize`，搜索归第一页，默认 1/10、最多 100；临时兼容旧 `pageNum`，有 `current` 时优先它。列表响应为顶层 `code/msg/rows/total`；详情为 `code/msg/data`；登录保留顶层 token。`getDataTable` 从实际 PageInfo 取总数。章节/资源/帖子的小集合继续返回数组，不伪造服务端分页。

请求层同时解析 HTTP 状态与现有业务 code，保留参考项目当前认证/拒绝响应行为。401 清会话并返回登录；403 保留会话、展示无权限；网络故障提供重试。后续任何新列表必须遵守相同契约。

## 5. Inclusive 实现与边界

学生主界面减少同时显示的信息，保留固定导航、明确主按钮、章节索引与前后章节。系统 emoji 只辅助辨认，旁边始终有英文标签；没有用表情代替权限或表单含义。支持键盘焦点、Skip to content、表单 label、错误/加载反馈、390px 窄屏布局。

正文使用可调整字号与行距；设置提供三种字号、高对比和减少动态。视频不自动播放，使用原生控件；有图片 alt、WebVTT 字幕和文字稿字段。正文按纯文本显示，不执行导师输入的 HTML。

朗读使用浏览器/系统已有语音，不引入收费云 TTS。已实现朗读、暂停、继续、停止、结束/报错状态恢复；可用性受本机英语语音及浏览器影响。本机无可用声音/语音服务失败时已显示英文提示，正文仍可阅读。自动化已核验该回退以及可控引擎下的生命周期；**没有将“按钮可点”写成所有设备有声输出均通过**。

这些是本版的可访问性措施，不代表已经由神经多样性学生实测或获得完整无障碍认证。真实学生试用反馈仍需收集。

## 8. 现有使用限制与下一步边界

上传限制沿用后端：图片 10MB、视频 100MB、WebVTT 1MB。支持哪些格式以现有上传检查为准；示例为 PNG、H.264/AAC MP4 与 WebVTT。没有自动转码、自动字幕或第三方视频云；导师需提供浏览器可播放的实际素材及准确字幕/替代说明。

当前前端为本机 Vite 开发服务器，不能把电脑关机后仍可访问当成本次交付。正式上线还需要按原部署标准设置站点、HTTPS、同源 API、数据库/Redis 与私有上传目录持久化备份；本轮未新增云服务、套餐或部署费用。开发地址仅绑定回环地址，没有额外对公网开放。

之后可沿用本次 feature/API/类型边界继续作业模块，再做每周心情模块；先确定真实字段与权限，追加 Flyway 版本，再实现对应页面与跨角色闭环。不得修改已执行 V1～V3、参考工程或无理由升级 Java 技术栈。
