# 课程收藏：FR-07、FR-08交付与验收

日期：2026-10-23。代码位于独立UP-SELF工程。本轮只交付课程收藏，FR-25自我效能评估之后再做。沿用六模块Java、Spring Security/JWT/Redis、MyBatis XML、PageHelper、BaseController及现有Vue结构，没有增加依赖或修改参考项目。

## 学生怎么使用

1. 选择Student登录，在 **My learning → My courses** 的课程卡片或课程详情点击 **Save course**。
2. 在 **My learning** 内打开 **Saved courses**，查看自己的收藏，点击 **Open course**继续学习。
3. 点击 **Remove from saved**取消收藏。刷新和重新登录后，状态以数据库为准。

只有本人已加入、已发布且未删除的课程可以收藏。导师、管理员及内部maintenance不使用学生收藏功能。收藏不是选课，也不改变学习完成状态。

课程归档、删除或撤销选课后，收藏页显示 **Course unavailable**，不返回原课程标题、简介或导师信息；学生仍可移除。重新获得访问资格时，尚未移除的收藏恢复展示。

## 实现及权限规则

| 项目 | 本轮方式 |
|---|---|
| 学生权限 | `learning:bookmark:own`，V8仅分配给学生角色 |
| 身份与归属 | 从当前登录用户取studentId，忽略请求中伪造的归属参数；Service再次限制学生身份，包括有通配权限的maintenance |
| 保存资格 | 校验课程当前发布状态及有效选课关系，使用课程原有行锁与课程/成员修改保持一致 |
| 重复操作 | `(student_id,course_id)`联合主键；重复/并发保存不重复建记录、不刷新首次收藏时间；重复取消安全成功 |
| 查询与分页 | 当前学生范围SQL；每页10项，按收藏时间、课程ID倒序；沿用`startPage()`/`getDataTable()` |
| 失效课程 | LEFT JOIN中限制课程访问范围，返回`course:null, available:false`占位；不借收藏绕过原课程授权 |
| 分层 | Controller → IBookmarkService/BookmarkServiceImpl → BookmarkMapper/XML；没有新建额外Maven模块 |
| 前端封装 | learning内独立API、类型、文案、共用BookmarkButton及SavedCoursesPage；复用CourseCard和公共分页/异步状态组件 |
| 状态维护 | 每个页面持有查询结果；按钮只在请求成功后更新，不建立跨账号的全局收藏缓存 |

## 接口约定

学生使用以下路径和现有Bearer学生会话。列表沿用TableDataInfo：`code,msg,rows,total`；保存/取消沿用AjaxResult：`code,msg`。业务错误码仍按项目现有约定从响应体判断。

| 方法 | 路径 | 用途 |
|---|---|---|
| GET | `/client/learning/bookmarks?current=1&pageSize=10` | 本人收藏分页列表 |
| PUT | `/client/learning/bookmarks/{courseId}` | 收藏，无需请求体 |
| DELETE | `/client/learning/bookmarks/{courseId}` | 取消本人收藏，包括失效项 |

列表单项为`{courseId,savedAt,available,course}`。可访问时`course`为现有课程对象并有`bookmarked:true`；失效时为null。现有课程列表与详情也返回当前学生的`bookmarked`，不返回其他学生收藏信息。

Controller保留与现有学习接口相同的`/learning/bookmarks`别名；管理端身份仍在权限/业务层被拒绝，不因此获得学生功能。

## 英文及inclusive交互

- 短英文配星形图标；图标只是辅助，按钮始终有文字。
- 保存状态提供`aria-pressed`和课程名称标签，支持键盘Enter。
- 等待时禁用重复点击；失败保留原状态，显示错误并可重试，不显示虚假成功。
- 提供空状态、加载、重试、刷新及操作结果提示；移除最后一页最后一项会返回有效页。
- 复用现有阅读偏好和响应式布局；390px手机宽度截图已检查，无页面横向溢出。
- 文案置于`bookmarkMessages.ts`并接入已有i18n；本轮没有开放多语言切换。
