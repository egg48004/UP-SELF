## 常见问题与准确回答

| 导师可能问 | 建议回答 |
|---|---|
| 进度怎么计算？ | 当前已发布章节中，学生标记完成的数量除以总数。打开章节只记位置，不推断掌握程度。 |
| 为什么不是每日心情？ | 实际需求确认采用每周、自愿记录；报告FR-21需同步修订。没有签到排名或强制连续打卡。 |
| 导师能看哪些心情？ | 当前有效已发布课程的学生，首次告知确认后只读等级/历史/趋势；私人备注不返回给导师。 |
| 管理员能批改吗？ | 当前由负责课程的导师批改，管理员维护账号和课程；这与原FR-53不同。 |
| 是AI判断风险吗？ | 没有AI、诊断或风险预警。图表只是用户主动记录的变化。 |
| 换电脑是否共享数据？ | 浏览器访问同一上线后端才共享；Git拉代码本身不带来后续新数据。 |
| 已经上线了吗？ | 当前本地已验收；Linux脚本和配置正在准备，没有购买服务器或部署。 |
| 61条都完成了吗？ | 当前严格对照为24完成、6部分、31未完成；MVP优先完成核心使用闭环，含FR-25自我效能。 |

## 故障时如何处理

- **端口占用**：停止自己多开的调试实例，不随意结束其他程序。
- **Unavailable**：看后端调试输出；确认Prepare backend任务成功、Mapper XML已复制，再重启后端。不能只刷新页面掩盖错误。
- **课程/作业不可见**：核对登录角色、当前负责/选课关系、课程/章节/资源/作业发布状态。
- **本周已记录**：这是正常规则；换预先准备的新演示账号，不删真实记录或调时间。
- **TTS没有声音**：确认浏览器语音可用，展示文字阅读和安全降级，不说所有设备都保证有语音。
- **网络/外部会议链接不可用**：继续展示本地真实功能，说明会议是外链；备用截图只能当历史证据，不能冒充当前成功操作。

## FR-25自我效能补充演示（约1分钟）

以上收藏阶段之后已完成FR-25。学生进入 **My check-in → Self-belief** → 首次查看共享告知并确认 → 一次回答一题，可Previous返回修改 → Save self-belief并确认 → 查看服务器计算的均值、下次可填写日期 → 刷新或重新登录确认保留 → 展示历史与图表/表格。需要演示完整多期趋势时使用明确标注的专属DEMO测试记录，不伪造实际学生历史。

导师进入 **Students → Student check-ins** → 打开学生 → Self-belief，只读日期、均值和趋势，没有逐题答案或保存按钮。管理员无此入口，也不能用直接网址绕过权限。心情的私人备注规则保持原样。
